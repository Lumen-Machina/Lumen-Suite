# Design language

Each Lumen plugin takes its look from one of Lumen-Machina's photographs. What changes from plugin to plugin, and what stays the same, is fixed so the suite reads as one family.

## Shared by every plugin
- **Layout and controls:** the same knob, meter, switch and button designs, the same spacing, the same layout grid.
- **Type:** the same typefaces and label sizes.
- **Name plate:** "LUMEN" and the plugin's name in the same place in every window.
- **Hardware gray:** knobs and hardware are always drawn in the photo's own gray (silver, granite or steel). This is the thread that ties the palettes together.
- **Photo credit:** each plugin shows its photograph and title.

## Taken from each plugin's photograph
- The palette: three to five colors sampled from the image.
- A background texture: a darkened, low-contrast crop, so labels stay readable.
- One accent color for values, active switches and meters, used sparingly.

## The plugins

| Plugin | Photograph | Palette |
|---|---|---|
| Lumen-Haze | An oak | Moss and silver |
| Lumen-Index | (shares Haze's look) | Charcoal, warm silver, deep red accent |
| Lumen-Oxide | Rusted orange farm machinery: springs, gears, shafts | Deep rust, implement orange, weathered steel, dry grass |
| Lumen-Serra | A granite ridge under a blue sky | Dark granite, granite light (`control`), sky blue (`signal`) |
| Lumen-Spectre | Three black-robed statues with gold masks against a gray sky | Matte black, stone gray (`control`), mask gold (`signal`), which also marks the knob notches and anything moving |

The exact color values live in Lumen-Core.
