# Roadmap

What is coming next, roughly in order. Plans change as each plugin is played with, and as feedback comes in.

## Now
- **Lumen-Index 1.4.1:** the first release for wider testing and feedback. Hardening and fixes across the board: chord names and spelling, more accurate Read, steadier timing in the standalone apps, and a tidier window. If you make music with chords, this is the one to try, and bug reports and ideas are very welcome.
- **Lumen-Serra 1.1** is out: the saw synth, with eight-note polyphony and 36 presets. Usable, but early. Bug reports and preset ideas welcome.
- **Lumen-Spectre:** a spectral filter, in active development, with 1.0 coming soon. You draw the Mask, then shape it with Smear, Ghost and Freeze, and move it with an LFO, an ADSR or an envelope follower.
- **Lumen-Core:** shared parts for the whole suite. The tape engine and the design book (the look every window is built from) are in; knobs, meters and the preset code are next.

## Next
- **VST3**, so the plugins work in Ableton, FL Studio, Cubase and Studio One as well as Bitwig, Logic and Reaper. Lumen-Index goes first, then Lumen-Serra. Lumen-Spectre gets VST3 from its first release.
- **Presets** across the suite: one save and load system, with factory presets for each plugin.

## Later
- **Lumen-Oxide:** the tape effect. The sound and presets are done; it's parked for now, and the plugin window is next when it comes back.
- A single download with the whole suite.

Lumen Haze, the first plugin, stays as an early demo. It isn't planned for release.
